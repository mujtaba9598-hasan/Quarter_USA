# Quartermasters — Web Development & AI Solutions

> California-based tech firm. Premium web development, AI integration, and custom digital infrastructure.

## Tech Stack
- **Framework**: Next.js 16.1.6 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Framer Motion 12, Lenis smooth scroll
- **3D**: Three.js / React Three Fiber / Drei
- **AI**: Claude API (Anthropic), Vercel AI SDK for streaming
- **Backend**: Supabase + pgvector (RAG), Redis (rate limiting + cache)
- **Email**: Resend | **Booking**: Cal.com | **Payments**: Stripe
- **Design System**: "Sovereign Nexus" — Deep Harbor + Burnt Copper (#C15A2C)

## Services (5 Modules)
1. **Web Development** — Full-stack Next.js/React/TypeScript applications
2. **Website Redesign** — Legacy platform migration to modern architecture
3. **Feature Injection** — Add AI, payments, auth, real-time to existing codebases
4. **Express Build** — Landing pages in 72 hours, MVPs in a week
5. **Custom AI Model Training** — Fine-tuning, RAG pipelines, prompt engineering, AI agents

## Pages
- Homepage, About, Contact, Services hub
- 5 service detail pages (web-dev, redesign, feature-injection, express-build, ai-model-training)
- Tech R&D, IT Services (legacy retained)
- Knowledge Base, Booking, Checkout
- Terms of Service, Privacy Policy
- Client Portal, Admin, Auth pages, 404

## Key Features
- **Q** — AI Senior Architect (Claude-powered, streaming via Vercel AI SDK)
- **Air Gap** — Semantic blocklist rejecting UAE/Middle East probes
- **Chameleon Engine** — 3 personas: Strategist, Architect, Operator
- **Iron Grip Pricing** — Deterministic state machine, server-enforced, 5-module pricing
- **Velvet Rope UI** — Standard vs Premium tier comparison
- **Magic Mirror** — Generative UI components (pricing grids, service comparisons, timelines)
- **3D Globe** — R3F globe with California HQ pin
- **ScrollStack, ClickSpark, GlareHover, SilkBackground** — Premium UI effects
- **Cookie Consent** — GDPR/CCPA geo-adaptive banner
- **Contact API** — Resend-powered contact form (POST /api/contact)
